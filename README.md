# mvp2
MVP da disciplina de Machine Learning.

Pode-se afirmar que a resistência do concreto está diretamente relacionada com o seu traço(proporções, em peso ou em volume dos elementos utilizados na mistura).

O objetivo deste trabalho é verificar a viabilidade do uso de um modelo de machine learning que, a partir das proporções dos elementos da mistura do concreto, possamos estimar sua resistência à compressão.
